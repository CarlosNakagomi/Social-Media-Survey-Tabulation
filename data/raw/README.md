# Raw Data



The raw Pew Research Center American Trends Panel Wave 144 (W144) microdata are not redistributed in this repository. Obtain the W144 public-use dataset from the official Pew Research Center source.



To reproduce the analysis, obtain the W144 public-use dataset and place the CSV file in this directory using the following filename:



`ATP_W144.csv`



Expected path:



`data/raw/ATP_W144.csv`



The analytical pipeline expects a dataset containing 10,454 respondent records and 195 variables.



Raw `.csv` and `.sav` files in this directory are excluded from version control through `.gitignore`.



After the dataset is placed here, run the six Python scripts in numerical order as documented in the project README.
